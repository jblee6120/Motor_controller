# Motor ALM

[HTML 사용설명서](static/guide.html)를 브라우저에서 열거나, 앱 상단의 `사용설명서`를 누르세요.

개인 모터제어기 프로젝트를 위한 로컬 GUI입니다. 브라우저에서 ASPICE 단계별 산출물, 요구사항, 시험 명세·결과, 변경·문제 기록, 추적 관계를 관리합니다. 인터넷 계정이나 추가 Python 패키지가 필요 없습니다.

## 실행

- macOS: `launch.command`를 더블클릭합니다. Terminal 창을 닫으면 서버가 종료됩니다.
- 터미널: 프로젝트 루트에서 `python3 alm/server.py`를 실행하고 `http://127.0.0.1:8765`를 엽니다.
- 다른 포트: `python3 alm/server.py --port 8766`

서버는 기본적으로 이 컴퓨터의 `127.0.0.1`에만 연결됩니다.

## 첫 실행 데이터

기존 `moteus_c1_aspice_draft` 폴더에서 SYS.1 요구 16개, SYS.2 요구 46개, 추적 링크 102개, Project Charter와 SYS.2 검토 문서 3개를 가져옵니다. 원본 YAML·CSV·Markdown은 수정하지 않습니다. 처음 가져온 뒤부터는 GUI 데이터가 별도로 관리됩니다.

## 사용 방법

1. 왼쪽에서 ASPICE 단계를 선택합니다.
2. 산출물을 열어 편집하거나 `새 산출물`로 추가합니다. ID는 자동으로 생성되고 재사용하지 않습니다.
3. 산출물 상세의 `연결`로 상위 요구, 설계, 시험 명세, 시험 결과를 잇습니다.
4. `점검`에서 TBD, 미평가, 빠진 링크를 확인합니다.
5. 시험 결과에는 실행 형상(HW Rev, FW Commit, 모터)과 증거 파일 경로를 남깁니다.

SYS.2 요구사항은 TBD, 미결정 항목 또는 기술 실현 가능성 평가가 남은 상태에서 `Approved`로 저장할 수 없습니다. 상태를 `Obsolete`로 바꾸면 ID를 유지하면서 사용을 중지할 수 있습니다.

## 저장과 Git

- 편집 내용은 `alm/data/alm.sqlite3`에 즉시 저장됩니다.
- 같은 내용과 항목 변경 이력은 `alm/data/workspace.json`에 자동으로 기록됩니다. 이 JSON 파일은 Git으로 버전 관리할 수 있습니다.
- SQLite 파일은 Git에서 제외합니다. 다른 컴퓨터에서 실행하면 `workspace.json`으로 데이터베이스를 다시 만듭니다.
- 상단 `JSON 내보내기`로 수동 백업도 받을 수 있습니다.

기존 YAML·CSV와 GUI 데이터를 동시에 편집하면 내용이 갈라집니다. GUI를 쓰기 시작한 뒤에는 `workspace.json`을 관리 기준으로 삼고, 원본 파일은 초기 자료로 보존하세요. 기존 `validate_requirements.py`는 원본 YAML·CSV만 검사하며 GUI의 최신 데이터에는 적용되지 않습니다. GUI의 `점검` 화면을 사용하세요.

이 도구는 ASPICE 업무 흐름을 돕는 개인용 초안이며 공식 평가 또는 인증 결과를 생성하지 않습니다.
